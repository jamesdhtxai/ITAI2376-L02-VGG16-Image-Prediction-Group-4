# Group 4 Contribution Guide

To keep the project consistent, each member should contribute the same basic pieces.

## Each Member Adds

1. One image experiment.
2. Original top prediction results.
3. Rotation and noise results.
4. One short reflection.
5. Two presentation slides.
6. Screenshots or other supporting evidence.

## Naming Suggestions

Use clear names such as:

- `results/first-last.md`
- `reflections/first-last.md`
- `results/first-last/` for screenshots

## Reflection Prompt

Write briefly about:

- What did you expect?
- What actually happened?
- What surprised you?
- What did you learn about VGG16 as a tool?

Focus on the learning process rather than explaining code you did not write.

## Group Comparison

Use the shared settings of **20° rotation** and **noise 20** so the group can compare results fairly. Additional experiments are welcome, but keep the shared comparison settings the same.
